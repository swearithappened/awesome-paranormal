# Contribution Guidelines

Thank you for considering a contribution. This list aims to collect primary sources: archives, databases, research bodies and tools that hold or examine actual case material. It is not a directory of blogs, opinion sites or content aggregators.

## What belongs here

An entry should be:

- A primary source, a research organisation, an academic publication, or a tool that helps examine case material.
- Actively maintained, or a stable public domain archive.
- Freely accessible, or accessible without payment for the core material.
- Substantial enough that a researcher would return to it.

## What does not belong here

- Sites that republish other people's accounts without attribution.
- Personal blogs, unless they host an original archive or investigation record.
- Paywalled databases with no free access tier.
- Sites that exist mainly to sell tours, equipment or services.
- Dead links and abandoned projects.

## How to add an entry

1. Fork this repository.
2. Add your entry to the appropriate section, keeping entries in the order established in that section.
3. Use this format: `- [Name](https://example.com) - Description of what it holds and why it is useful.`
4. Start the description with a capital letter and end it with a period.
5. Keep descriptions to one sentence where possible, and describe what the resource contains rather than praising it.
6. Check that the link works and uses HTTPS where available.
7. Open a pull request with a title describing what you added.

## Adding a new section

If a resource does not fit any existing section, open an issue first to discuss whether a new section is warranted. Sections should hold at least three entries.

## Removing an entry

Open an issue if a resource has gone offline, moved behind a paywall, or no longer matches the criteria above. Include evidence where possible.

## Self-submission

You may submit a resource you own or work on. Describe it neutrally and factually, exactly as you would describe someone else's. Entries written as promotional copy will be edited or rejected.
